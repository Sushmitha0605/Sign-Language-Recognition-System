# Real-Time Sign Language Recognition System

## Overview

The Real-Time Sign Language Recognition System is a computer vision application that detects hand gestures using a webcam and recognizes selected sign language alphabets in real time. The system forms words by combining detected letters and provides gesture-based deletion for improved usability.

---

## Features

- Real-time hand tracking
- Sign language alphabet recognition
- Word formation
- Gesture stability detection
- Delete gesture using a closed fist
- Live webcam interface

---

## Technologies Used

- Python
- OpenCV
- MediaPipe
- NumPy

## How to Run

1. Clone the repository.

```
git clone https://github.com/YOUR_USERNAME/Sign-Language-Recognition-System.git
```

2. Install the dependencies.

```
pip install -r requirements.txt
```

3. Run the application.

```
python main.py
```
